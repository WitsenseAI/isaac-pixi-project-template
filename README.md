# Isaac pixi project template

A starting point for Isaac Sim and Isaac Lab projects that installs the
same way on Windows and Linux, managed by [pixi](https://pixi.sh).

| Package | Version |
|---|---|
| Isaac Sim | 6.2.0.0 |
| Isaac Lab | 3.0.0 |
| PyTorch | 2.11 (CUDA 12.8) |
| Python | 3.12 |

```bash
pixi install
pixi run check
```

See [setup.md](setup.md) for requirements, per-OS steps and
troubleshooting.
